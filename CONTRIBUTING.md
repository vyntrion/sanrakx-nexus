# Contributing

Thank you for considering a contribution to SanrakX Nexus.

## Workflow

1.  Open an issue or describe the intended change.
2.  Create a feature branch.
3.  Keep changes focused and documented.
4.  Add or update tests.
5.  Run relevant test suites.
6.  Update API or security documentation when behavior changes.
7.  Submit a pull request with a concise summary, test evidence, and
    known limitations.

## Coding expectations

-   Prefer readable, typed Python and small modules.
-   Validate untrusted input at system boundaries.
-   Use parameterized database operations.
-   Do not commit secrets, private logs, or real credentials.
-   Keep detection rules explainable and include test fixtures.
-   Do not add arbitrary shell execution or unauthorized offensive
    capabilities.

## Reporting security issues

Do not publish sensitive exploit details or secrets in a public issue.
Use a private disclosure channel if one is established by the
maintainers.

## Scope

Contributions should prioritize defensive monitoring, investigation
quality, correctness, accessibility, and secure engineering.
